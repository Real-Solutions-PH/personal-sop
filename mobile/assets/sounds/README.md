# Notification sound

`unfurl.wav` is the sound every Unfurl reminder and push plays: three soft
notes rising (D5, A5, D6), about 1.5 seconds, calm rather than urgent.

- **Source:** generated by `make_unfurl.py` in this folder (Python standard
  library, deterministic). No sample, recording or third-party audio is used.
- **Licence:** original work of Real Solutions PH for Unfurl, dedicated to the
  public domain under CC0 1.0; bundling and redistribution need no notice.
- **Where it is wired:** the `expo-notifications` plugin in `mobile/app.json`
  bundles it (iOS app bundle, Android `res/raw`); the phone's scheduled
  reminders name it (`src/prototype/local-reminders.ts`, Android channel
  `reminders`), and so do server pushes (`backend/app/shared/push.py`).

To change it, edit `make_unfurl.py`, run `python3 make_unfurl.py` here, and
ship a new native build: the file lives in the app binary.
