# Sleep (from Apple Health) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Show last night's sleep, the week's average and a bar per night on Fitness and Today, with a week/month detail screen, read from Apple Health.

**Architecture:** Mirrors Steps exactly: `mobile/src/prototype/health.ts` reads HealthKit read-only, nothing synced, no backend. A `SleepCard` beside `StepsCard`, a `SleepDetail` at `/fitness/sleep`. `useDays` in `steps-card.tsx` is generalized so both cards share the read/refresh hook.

**Tech Stack:** Expo SDK 58, `@kingstinct/react-native-healthkit` 16.2.0, jest-expo.

**Spec:** Shape agreed in chat 2026-10-29. Cut from that shape, deliberately: manual log, quality 1–5, trophy, share card, launcher tile. Those need a server table + scoring; Health already holds the data. Phase 2 if wanted.

## Global Constraints

- Read-only. No HealthKit writes (`NSHealthUpdateUsageDescription` stays `false`).
- A night belongs to the day you wake: night of day D = `[D-1 18:00, D 18:00)` local.
- Asleep = `CategoryValueSleepAnalysis` 1, 3, 4, 5. `inBed` (0) and `awake` (2) never count.
- Overlapping samples (Watch + iPhone) are merged, never double-counted.
- Goal: 7h (420 min). Display `7h 05m`.
- Expo Go gets sample data, like Steps.
- Gated by the Fitness area switch on Today (sits in the `s.enabled.fitness` block).

## Review Focus

- Two sources overlap (Watch + phone) → minutes counted once. Test in Task 1.
- Sample straddles 18:00 → split between the two nights by clipping. Test in Task 1.
- No sleep data at all (no tracker) → card renders nothing, detail shows an empty state, no "0h" bars. Test in Task 2.
- Average skips nights with no data (a missing night is not a 0h night). Test in Task 2.
- Existing users who already answered the Health sheet: adding SLEEP to the read set makes `healthAsked` false once, so Connect shows again until tapped. Accepted; no test.
