# ChatMessage

The conversation. The person's messages sit right in a neutral `muted` bubble with the time below in mono. **Fern's replies stand out**: the glowing orb, "Fern" in `primary`, and the reply in a `mist` bubble with a 1 pt `frond`-tinted border, so Fern is the only coloured voice on screen. Numbers in Fern's replies are mono, with units and the comparison's date.

Suggestions are outline pills under Fern's reply. While Fern works, the orb sways and the line says what it is doing ("Looking at October's transport"), followed by three soft dots.
