# IconButton

Icon-only control, always a 44 pt round hit area and an accessible label.

Plain (`foreground` icon), `quiet` (`muted-foreground`), `soft` (on `muted`), `solid` (on `primary`: the composer's dictate and send buttons, the only filled icon buttons). Icons 18 pt, stroke 1.75. Pressed: a `accent` circle behind the icon. Counts are a `foreground` pill with the number in Geist Mono, never a red dot.
