# FernScreen

Fern's full chat. The header carries the 40 pt orb, Fern's name and the history and settings buttons, as the app has them. One sentence becomes three records, each with its exact values and its own Undo; a question gets a number, a comparison and a small chart inside Fern's bubble. Fern's replies are the only coloured surfaces on screen, and the floating composer with the large gradient talk button keeps speaking one thumb away.
