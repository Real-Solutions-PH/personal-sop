# TabBar

Today, Plan, Fern, Stats, Me, as the app has them. Side tabs: lucide icons 22 pt at 1.6 stroke (active 2.0) and Geist Medium 12 labels, `foreground` active and `muted-foreground` otherwise, a hairline above.

**The Fern button** rises 30 pt above the bar, as it does today: a 60 pt disc with the gradient from `frond` to `moss`, a 3 pt `background` ring that cuts it out of the bar, `shadow-fern`, the white fiddlehead, and a `sprout` halo that breathes (opacity 0.22 to 0.40, scale 1 to 1.08, 2.2 s). It opens Fern's drawer over any screen; the mark turns into a close icon while it is open.
