# RecordCard

The receipt Fern shows after filing something: the most specific surface in the product.

Plain `card`, hairline border. Header: module dot, area and type ("Money · Expense"), and the state as a word with an icon (`good` "Saved", `warn` "Check this", muted "Undone 12:44"). Then the record's name, then **every field Fern filled** as a label/value list with values in Geist Mono, then **the words it came from** ("From “spent 250 on lunch”"), so the person can see exactly what was understood. Actions are text buttons (Undo, Edit). When Fern needs an answer it asks one plain question and offers one filled button that names the outcome ("Start Push day").
