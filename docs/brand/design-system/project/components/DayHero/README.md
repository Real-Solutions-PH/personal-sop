# DayHero

The first card on Today (the app's `DayHero`): today's due items done across every enabled area. A 112 pt ring with the percentage in mono, the headline ("2 to target", "Target hit", "Day complete" or "Free day"), the count against the target, and two chips that open Stats: the on-target streak and the Life Score. Below, one row per area with something due: its bar in the area colour, the target tick, and "done/due" in mono. Restyled only: flat card, mono numbers, area colours on the bars.
