# ModuleStats

The stat strip at the top of every area card on Today (the app's `HabitsStats`, `TasksStats`, `FitnessStats`, `FinanceStats`): three numbers in Geist Mono 18 with an 11 pt label, a value turning `good`, `warn` or `bad` when it means something, and seven days of bars, past days in a tint of the area colour and today in full, with weekday initials (today bold). Restyled only.
