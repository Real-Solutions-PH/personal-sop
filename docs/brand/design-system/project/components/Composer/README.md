# Composer

The bar where everything is logged, the most important control in the app.

It floats: `card` surface, top corners `radius-hero`, `shadow-composer` above it. Optional hint chips tell Fern what to expect. The input pill is 52 pt, placeholder "Message Fern…" (the companion's current name), with the camera inside. **The talk button** is a 56 pt circle with the orb gradient and a white mic, the biggest touch target on the screen, because speaking is the fastest way in. Once text is typed it becomes Send (same size, same gradient).
