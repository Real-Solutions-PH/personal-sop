# Row

A line in a list: a task, a transaction, a setting. At least 64 pt; title in `body`, detail in `detail` with the module dot first; value on the right in Geist Mono (money signed: `−₱250.00`). Done items keep their place with a filled check and a muted title, and show when they were done.

Swipe actions: More on `muted`, Delete on `destructive` with `on-accent` text. Every swipe action also lives in the row's menu.
