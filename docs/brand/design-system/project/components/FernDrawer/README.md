# FernDrawer

Fern over any screen. Tapping the Fern button raises this drawer to about two thirds of the screen: grabber, the 40 pt orb, "Fern" and where it is listening ("Listening on Today"), a button to open the full chat, the latest exchange, and the composer. The screen behind dims to 55% black so the conversation is the only thing in focus. It opens with a spring and closes in 220 ms; dragging down dismisses it.
