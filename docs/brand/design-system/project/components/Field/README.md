# Field

A labelled input. Forms are the fallback; telling Fern is the first way to log.

48 pt tall, `card` fill, 1 pt `input` border (3:1 on card in both themes), `radius-control`, text 16 pt so phones don't zoom. Numbers are set in Geist Mono with the unit as a muted suffix (`250.00 PHP`, `72.4 kg`). Label above in `caption`; optional helper text below in `muted-foreground`. Error: a 2 pt `bad` border and one line below, with an icon, that says what to enter.
