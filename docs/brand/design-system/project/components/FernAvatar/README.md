# FernAvatar

Fern's face, the same object as the app icon: a circle with the orb gradient (`moss` bottom-left, `frond`, `sprout` top-right), the white fiddlehead at 72% of its width, and a soft `sprout` glow behind it.

At rest it breathes slowly (1.8 s each way). While Fern is working the breath quickens (0.5 s), the glow brightens and the frond sways ±9°, as if unfurling. Under reduced motion it is still. Sizes: 28 beside messages, 40 in the chat header, 72 on the welcome screen. Below 16 pt show the orb without the mark.
